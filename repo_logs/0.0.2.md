## New Features

- **CGI Strip Prefix** (`--enable-cgi-strip-prefix`): Auto-strip debug output before CGI HTTP headers
- **Log color** (`--enable-log-color`): ANSI color in timestamps via `isatty()` detection
- **Log buffer size**: `LOG_SANITIZE_BUF_SIZE` configurable (default 2048)
- **CVE tracking**: `SECURITY.md` + `VULN_TRACKING.md` with full CVE status table
